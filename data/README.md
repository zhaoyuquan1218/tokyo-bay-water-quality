# Data products

`processed/regional_quarterly.csv` is generated from the verified open Zenodo workbook. It contains all region-quarter-variable combinations for 1981-2021 and retains unavailable or quarantined values as missing. Units are standardized in labels only; no concentration conversions are performed. The original data are attributed to Zhao (2026), CC BY 4.0; see [provenance](../docs/data-provenance.md).

The source release contains DOC and nine environmental variables. It does not contain TOC, POC, COD, DCOD, station identifiers, or bottom observations. The approved six-station mapping is retained as context and for the optional local station QA adapter. Published regional values are never reassigned to individual stations.
